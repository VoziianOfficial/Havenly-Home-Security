# Havenly — Home Security

Многостраничный сайт агрегатора. Содержимое ZIP загружайте в корень PHP-хостинга. Требуется PHP 8.1+ с настроенным mail().

Настройки находятся в config/config.js: companyName, legalName, logo, favicon, browserTitle, email, disclaimer, formSuccessMessage, contactEndpoint и pricing. Сохраняйте JSON-формат внутри window.SiteConfig. PHP читает этот же конфиг. В названии вкладки и дисклеймере поддерживается {companyName}.

Почту hello@havenly.example замените на реальную. До замены обработчик не отправляет письма. После настройки проверьте доставку на хостинге. Успешный ответ появляется только при подтверждении отправки сервером, а не на любой HTTP 200. Sites не исполняет PHP.

Фото, иконки, AOS и Swiper включены локально. Шрифты подключаются через Google Fonts. Источники фотографий находятся в assets/photo-sources.json; лицензии библиотек — в assets/vendor/LICENSES.txt. Референсные фотографии и знак Blackcats требуют соответствующих прав для публичного использования.

На главной 15 секций; камеры — 11; сигнализация — 10; доступ — 10; About — 5; Contact — 3. Горизонтальный аккордеон услуг работает по нажатию. Фотопанорама меняется при наведении, фокусе или нажатии. На сервисах можно выбирать зоны просмотра, приближать фото и переключать табы клавиатурой.

Просмотр зон — интерактивная иллюстрация на реальных фотографиях, не подключение к камерам. Цены в pricing — демонстрационные значения. Тексты политик необходимо привести в соответствие с фактической работой оператора перед запуском.

Анимация печатания использует ступенчатое раскрытие заголовка без изменения текста или разбиения на буквы. Поддерживается reduced motion. Иллюстрации переведены в WebP без потерь; фотографии оптимизированы с сохранением подходящего для отображения разрешения.
